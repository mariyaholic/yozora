These are original simple symbols made for Yozora's Discord presence.
They use original geometric proportions, with no wordmark or text.
They are referenced by HTTPS raw.githubusercontent.com URLs from main.
Regenerate the 512×512 PNG and SVG assets with `python3 assets/presence/generate.py` (requires Pillow).
Using YouTube-style marks next to the YouTube name is Maria's call (trademark).
