How video detection works

Yozora matches the Edge or Chrome window title to the playing video (“… - YouTube”, “channel - Twitch”). When exactly one window matches and that site is on, it reads the window’s address bar through Windows UI Automation and keeps only the video ID or channel name. Nothing else from the browser is kept.

YouTube shows the video thumbnail and a watch button. Twitch shows the stream’s live preview and a watch button; offline channels, VODs and clips get the Twitch symbol instead. While a site is off, its matches are hidden from Discord.

Background Edge tabs reads tab names from up to 8 windows when no title matches. It finds YouTube only and shows the symbol, without a thumbnail or button. App filters such as msedge still block the YouTube Music PWA.
