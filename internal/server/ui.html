How YouTube detection works

YouTube is off by default and needs Browser media. An exact Edge or Chrome window title match shows Watching YouTube. With a video ID, it uses the video thumbnail (or symbol) and a watch button; without one, it uses the symbol on Discord and the media thumbnail here, without a watch button.

Detection checks when the browser track or its play/pause state changes, or while it is not yet classified. With YouTube on and exactly one matching window, Yozora reads that window’s address bar through Windows UI Automation and keeps only the video ID (active tab only, best effort). With YouTube off, matching tracks are hidden, even if several windows match.

Background tab detection is off by default. When no window title matches, it reads tab names from up to 8 browser windows (designed for Edge) at the same checks. Matches use the symbol only, without a thumbnail or button; with YouTube off, matches only hide tracks.

Custom app filters such as msedge still block the YouTube Music PWA; its source toggle cannot override them.
